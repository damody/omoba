# MOBA 操作手冊

此頁列出預設操作。可在右上角「操作設定」或 Esc 選單改鍵；畫面上的快捷鍵標籤會跟著更新。舊的個人設定會保留，實際按鍵以設定頁為準。設定會立即保存，改鍵衝突或保存失敗時維持原設定。

## 地圖與單位規則

目前三路訓練地圖的基地位於左下與右上，中路斜向連接，上下路沿外側繞行，河道沿另一條對角線。每方每路有三層塔；地圖包含雙方野區、河道及大型中立營地，共16個營地、32隻野怪，野區牆群會阻擋移動。任一路的三層敵塔全部摧毀並退休後即可攻擊敵方基地；目前沒有水晶與基地雙塔機制。

每30秒出一波兵，每路每方3近戰、3遠程，每第三波增加1砲車。普攻或成功的指定單位技能攻擊敵方英雄時，附近敵方小兵會護主；正在攻擊塔的小兵繼續拆塔。塔也會因實際英雄傷害而轉火。護主需要攻擊者可見且在索敵範圍內，過期或目標失效會解除。

閒置與攻擊移動不會自動拉中立野怪，請明確點選攻擊。狼、鳥與石怪營地有附屬怪；攻擊其中一隻會讓整組接戰，每隻分別給予擊殺獎勵，清空最後一隻才開始整營重生計時。野怪追擊越界會先消耗耐心，接著軟返回並恢復生命；此時回到營地範圍內攻擊可重新接戰，範圍外傷害無效。持續未重新接戰會進入硬返回，期間免傷並較快回家，抵達後恢復滿血。這些是本專案可調整的訓練規則，模型沿用既有資產。

施放前開啟預覽時，可看到公開射程圓、點施放方向線／箭頭與落點，以及確認／取消方式。射程內外使用不同顏色並顯示距離；QWER未學習或冷卻中會顯示原因。單位技能會提示是否已指向可見單位；射程未知時不猜測數值。這些是瞄準輔助，不代表技能一定能命中。取消、失焦、死亡或操作來源失效時，預覽會一起關閉。

## 啟動與離場

從 clone 根目錄執行 `run_ue.bat --moba`，會沿正式 MOBA 流程建置、檢查內容並開啟選角；預設是一位真人與伺服器 Bot。引擎位於 `D:/UE5.8` 時會自動找到，也可執行 `run_ue.bat --moba --interactive-selection --ue-root D:/UE5.8` 明確指定。已完成建置時可加 `--no-build`，缺少或過期產物會明確失敗，不切換其他 profile。進階配方、多位真人與 LAN 用法見 `run_ue.bat --moba --help`。

`run_ue.bat --help` 不啟動引擎或對局。無參數的 `run_ue.bat` 仍是既有 TD；也可用 `--td` 明確選 TD。

對局結束會依公開結果顯示勝利／敗北／平手。「離開對局」會退休當前輸入與 HUD、清理場景並停止本機 runtime，再沿 Unreal 的退出流程離場。

從 `run_ue.bat --moba` 啟動的全本機真人場次，結算面板另提供「再玩一局」。按下後顯示「等待其他玩家…」，仍可離場取消；所有真人都準備，且舊局所有原始程序確認退出與清理完成後，才重新開啟選角，使用新設定、新輸出與新程序。手動關窗、崩潰、來源失效或清理失敗都不會自動重開。直接使用單場 role launcher、remote／部分本機的 LAN、dedicated 與限時結果擷取入口維持單場行為，不顯示未提供的下一局能力。

世界名牌的己／友／敵／?及青／綠／紅／灰血條代表目前公開的關係，色盲模式會改用對應色盤；低生命值另有「!」提示。未知關係不會依玩家編號猜測成友軍。

世界名稱列只放名稱，精確生命值看自己的操作列或選取目標資訊。小兵、召喚物與建築的血條依目前鏡頭顯示，非英雄最多64個，優先選取／指向目標及建築；關係或來源失效時撤銷。文字放大同時調整名牌尺寸，長名稱保留有界省略。小地圖顯示「視野未知」時，不能把缺少正式視野資料理解成整張地圖可見。

## 操作回覆

移動、攻擊、施法、回城、Stop／Hold等操作會顯示目前的指令狀態。「已送出」表示已交給連線流程，尚待對應回覆；「已確認」表示收到同一指令的確認，不代表已走到目的地、已造成傷害或技能效果已完成。「遭拒絕」表示收到拒絕回覆，本機能確認的冷卻、距離或資源問題仍顯示原有原因。

連線結果不明或等待逾時會顯示「尚未確認」，不當成成功，也不自行重送。較舊指令的晚到回覆不會蓋過最新操作；死亡、離場或換操作來源會清除舊回覆。購買／出售／撤銷依商店收據顯示，守衛依自身公開狀態更新。

## 改鍵與按住指令

快捷鍵列分為「主要」與「次要」，可各自改鍵或解除；新增設定的次要鍵預設未綁定。解除其中一欄不會清掉另一欄。搜尋欄可依動作、分類或兩欄按鍵篩選，清除搜尋會恢復列表；篩選不會放寬改鍵衝突檢查。

「按住世界指令」可設定初次延遲與後續間隔。兩個綁定同時按住時共用發送節流，放開其中一鍵會保留另一鍵，最後一鍵放開才結束；重新按住會重新計算初次延遲。相同目標位置會去重。設定變更會取消原先的施法瞄準，再按新鍵即可重新開始；舊鍵放開不會確認新的瞄準。

## 單位選取

世界左鍵選取目前公開的英雄、友軍、敵人、建築或中立單位，顯示其名稱、敵我關係與生命值；滑鼠移到目標資訊上可查看公開種類與隊伍。選取本身不送出遊戲指令；點地板清除，Esc在取消目前施法、A瞄準或關閉介面之後清除選取。合法右鍵指定攻擊也會更新目標，地板移動保留目前選取。

選取鍵可在操作設定改成滑鼠或鍵盤的主要／次要鍵。一般左鍵選取與已武裝的施法／A確認是不同情境，預設可共用左鍵；其他快捷鍵仍檢查衝突。滑鼠移到公開單位會有hover外圈，選取外圈較大；目標隱藏、死亡、世代替換或玩家來源失效會清除資訊與輪廓。自身死亡時仍可查看其他活著的公開單位。TD模式維持原本左鍵放置與塔選取。

只選英雄預設按住 `~` 鍵啟用（TargetChampionsOnly），可改主要／次要鍵，或在操作設定勾選切換模式。啟用時上方顯示「只選英雄已啟用」，左鍵選取、hover、直接攻擊及指定單位施法只挑公開英雄；小兵、野怪、建築與眼位會被略過。一般右鍵點不到英雄時仍可移動，只攻擊點擊則不移動。地點技能、自用與 A 攻擊移動維持原規則。失焦、modal、改設定、死亡或來源失效會清除舊啟用狀態。

| 停止目前動作與佇列 | S |
| 保持位置 | H |
| 技能 | Q／W／E／R |
| 召喚師技能兩槽 | D／F；各槽可獨立選擇施法模式 |
| 升級技能 | Ctrl＋Q／W／E／R |
| 對自己施法 | Alt＋Q／W／E／R，仍需該技能支援自身目標 |
| 臨時覆寫施法模式 | Shift＋Q／W／E／R，模式可在設定中選擇 |
| 回城 | 主要預設 B，次要預設未綁定，實際按鍵以設定頁為準。對局允許且英雄存活時可提出回城請求；畫面顯示已公開的回城狀態與剩餘時間，客戶端不預測完成 |
| 六格物品 | 新設定預設 1／2／3／5／6／7；Alt＋對應鍵自用。六格可點。操作設定裡每一格可分別選普通、快速、指示器，並顯示該格目前的主要與次要鍵 |
| 獨立飾品／眼位 | 4；依配備顯示充能、冷卻與可用狀態，可改鍵 |

每個技能與物品格可分別選「普通」「快速」「指示器」：普通模式按下後瞄準、左鍵確認；快速模式按下即送出；指示器模式按下顯示、放開原施法鍵送出。無目標物品在三種模式下都於按下時送出；Alt 自用須該物品允許自身目標。

道具卡顯示圖示、快捷鍵、冷卻與可用狀態，滑鼠停留可查看名稱與完整說明。點自身道具卡立即使用一次；點地點或單位道具卡進入普通確認，與實體按鍵的施法模式分開。被動、空格、冷卻中與死亡時不能使用，點擊也不會變成世界移動或攻擊。右鍵或 Esc 取消尚未確認的物品。

Shift 覆寫進入指示器模式後，單獨放開 Shift 不會取消，仍由原施法鍵放開時確認。點擊一般介面不會確認世界施法，可用 Esc 取消。冷卻、資源、目標與升級條件依遊戲公開狀態決定；死亡或階段不允許時仍保留物品資訊並顯示不可用原因。

右鍵取消世界瞄準後，合法的世界右鍵仍可執行一次正常移動或指定攻擊。失焦、開啟設定、改鍵或英雄來源失效會清除舊瞄準；之後放開舊鍵不會補送施法。指定單位技能只使用當前公開且符合技能敵我規則的目標，不會把空地或隱藏單位當成合法目標。

Shift＋A 是獨立的立即攻擊移動，與 Shift 指令佇列分開。舊版物品 1–6 的個人改鍵不會被默默覆寫；飾品若與舊綁定衝突，請依設定頁的實際綁定操作。

D／F 使用伺服器明確配備的召喚師技能，各自顯示圖示與冷卻。地點技能支援普通、快速與指示器模式，自身技能直接自用；不支援的 Alt 自用不會送出。未配備、能力尚未開放、冷卻或死亡時不能施放。失焦、面板阻擋、改鍵與英雄身分變更會清除舊瞄準；客戶端不自行預測瞬移或補血。

## 聊天與角色互動

Enter 開啟隊伍聊天，Shift＋Enter 開啟全體聊天；Enter 送出，Esc 取消。文字輸入期間 QWER、A、Space 等按鍵會留在文字框，不會觸發遊戲操作。聊天使用一般 Slate 文字輸入介面。

Z 切換收到訊息的歷史，Esc 關閉。歷史可用滾輪捲動；放大文字時仍可捲讀完整訊息。名冊區提供明確「靜音」及「解除靜音」，重新連線後即使尚未收到訊息也可操作。畫面的「已排隊」表示尚待伺服器回覆，不能當成已送達或靜音成功。失去焦點、斷線、換玩家或通訊來源時會取消未送出的草稿。

操作設定的「允許全體聊天」同時控制全體訊息傳送與顯示，隊伍聊天仍可使用。Ctrl＋1–5 發送五種原創角色互動。

G 點按發送一般訊號，V 點按發送警戒。按住 G、V 或 Alt／Ctrl＋左鍵可拖曳選擇八方向訊號，放開送出；T 按住可選擇原創表情。右鍵或 Esc 取消，失去焦點或變更操作設定也會取消。小地圖訊號不受「允許小地圖施法」設定限制。這些按鍵可在操作設定中修改；舊設定發生衝突時保留已保存的綁定。表情中心放開不發送，訊號仍使用按下時的合法地點。

## 音量與提示

操作設定的「音效」區提供主音量、音樂與音效滑桿。拖曳時即時預聽，放開後保存；鍵盤可聚焦滑桿，以 Enter 進入調整、方向鍵增減、Enter 完成。重開設定保留數值。「語音」目前沒有原創素材，因此停用並明示原因。

公開移動、攻擊、施法、命中、生命恢復、陣亡、重生與自身回城狀態會驅動原創音效；重新連線的初始生命狀態不重播舊事件。主音量為零會停止播放，恢復音量只恢復當前有效的環境音／回城引導，不重播先前一次性音效。音效來源與匯入記錄位於專案原創素材 provenance。

「播放隊伍訊號與表情音效」可關閉隊伍通知音效；「顯示音效字幕」可獨立切換字幕，主音量或音效靜音時仍可顯示。兩個選項都會保存。收到有效隊伍訊號、目標投票、表情或狀態通知時顯示對應提示；靜音玩家、已過期事件及重新連線的歷史不重播。表情字幕使用本專案原創內容。

## 模式、游標與搖桿

只攻擊點擊與只移動點擊可在操作設定中綁定，預設未綁定；前者沒有合法敵人時不移動，後者點到敵人仍只移動。攻擊移動依游標選敵、自動攻擊與只選英雄是不同偏好；關閉自動攻擊仍可明確下達攻擊指令。設定保存後，戰鬥偏好須等伺服器公開狀態相符才會顯示已套用。

點擊移動是預設模式。對局規則允許時，可提出切換鍵盤移動模式，設定WASD或自訂方向鍵；模式切換以遊戲公開結果為準，切換時限已過或條件不符會顯示原因。設定頁會檢查方向鍵與技能等操作的衝突，實際快捷鍵以當前畫面標籤為準。

操作與游標輸入偏好可按全域、輸入模式或當前英雄保存；還原目前層或單一欄位後會重新繼承上層。文字、HUD顯示與音量偏好為全域共用。

在「游標與搖桿」先綁定上／下／左／右四個游標鍵，再啟用鍵盤游標。可另設加速、精細移動、游標速度與搖桿死區；缺少必要鍵或有衝突時不會套用修改。搖桿游標與英雄方向可各自指定橫／縱軸，預設右搖桿游標、左搖桿英雄方向；英雄方向只在已公開的鍵盤移動模式生效。

啟用、換設定或失焦後，先把要使用的搖桿回到中央再操作。失焦或來源切換會清除舊的按住狀態。世界與小地圖使用同一個可改鍵的瞄準確認操作，支援主要／次要滑鼠或鍵盤鍵；確認與單位選取可共用按鍵，依當前狀態執行對應操作，右鍵保留取消。
