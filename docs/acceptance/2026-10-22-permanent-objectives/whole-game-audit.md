# 全遊戲盤點：永久史詩累積與多項獎勵

接續17系統盤點，優先補永久目標成長，保留既有左下／右上地圖、塔／小兵行為、野怪回頭、個人Buff傳承與限時隊伍疊層。

- additional_objective_buffs提供每營地最多4個額外隊伍獎勵，缺欄空；同營地重複ID拒絕、同map同ID政策／scope一致、每scope最多32種符合既有lease容量。
- 隊伍duration0表示永久，必須死亡保留且不可個人傳承；個人Buff仍有限期限，原限時隊伍Buff不改成永久。
- 永久lease expires=None，BuffStore明確raw MAX永久標記不扣時間；snapshot沿既有-1、Unreal持續生效契約，ABI33維持。
- 南史詩原120秒護甲Buff保留，另授予原創每層5攻擊、最多4層的永久傳承。真實主體致死授予多項，重複Outcome不重授，跨死亡／重生保留，結束與新局清除，digest包含政策／層數／Option期限。
- 新回歸包含超長時間、永久tick、真實營地重生與疊層、死亡隊員／重生、pause／結束；正式60Hz三層永久snapshot與匿名死亡＋native DeathTick後重生保留。

剩餘小兵光環／野怪分裂、全隊經濟差補償、更多公告、持續引導／特殊幾何／施法動畫、完整召喚複本／回滾、塔皮與美術；MVP33/44／11外部ACK／LAN／DPI／效能待驗維持。此為原創內容規則，不宣稱逐項複製特定LOL版本。
