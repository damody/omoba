# H04 阿市：驗收

status: implemented

kit 狀態：`supported`。五招（含 D 欄）都有 handler 與測試，以完整 kit 建置。

| 技能 | 實作 |
|---|---|
| `c17_light_chain` | 對敵：host tether，到期依距離結算傷害與定身；對友：3 秒受傷 −30～60% |
| `c17_victory_blessing` | 全圖單一友軍（含塔）護甲／攻擊%／回血 16 秒 |
| `c17_divine_strike` | 點 200 範圍魔法傷害 |
| `c17_aurora_guard` | 前搖 1 秒；敵人受 max(固定, 最大生命%)；友軍由 host ally_area_restore 回復最大生命% |
| `c17_devotion`（D） | auto_learn 出生學會；物理格擋 20；施法時英雄 UnitScript 送出 800 範圍回復 5% 生命／4% 法力 |

實機（quick 地圖、10 分鐘內）要看：
1. Q 對敵方英雄：3 秒後光鍊斷開，距離遠傷害高，距離近定身久。對友方英雄：3 秒內受到的傷害明顯變少。
2. W 對遠處友方英雄與友方塔各施放一次；不能對敵人施放。
3. E 對兵群：200 內每個敵人扣血一次。
4. 6 級 R：1 秒後範圍內敵人大量扣血，友軍大量回血。
5. D：開局就有。每次施放技能後，自己與附近友軍回一點血與魔。
