# H06 淺井長政：驗收

status: implemented

kit 狀態：`supported`。五招（含 D 欄）都有 handler 與測試，以完整 kit 建置。

| 技能 | 實作 |
|---|---|
| `b08_fang_slash` | G-1 直線穿透（寬 175、1200） |
| `b08_flash_cut` | 瞬移到目標身旁 100，傷害＋暈眩 0.3＋燒魔封包 |
| `b08_living_soul` | 被動攻速；施法疊層由英雄 UnitScript（`unit_script = true`）呼叫 |
| `b08_sky_fang` | G-1 直線穿透（寬 500、3000） |
| `b08_endless_fang`（D） | auto_learn：16 級自動學會；1800 魔法傷害＋暈眩 2.2 |

實機（quick 地圖、10 分鐘內）要看：
1. Q 朝兵線施放：刀牙穿過整條兵線，每個敵人扣血一次。
2. W 對遠處敵方英雄：瞬移到身旁、扣血、短暫暈眩、法力下降。
3. E：連續施放技能時普攻傷害逐層變高（最多 4 層），8 秒沒施放就消失。
4. 6 級 R：寬刀牙飛 3000，沿途敵人大量扣血。
5. D：16 級自動出現，不用加點。
