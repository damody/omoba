# H02 伊達政宗：假設與改編

結構化版本在 `source.lua` 的 `assumptions`。來源：`damody/nobugg_official@ca6ee86`，B04 current 版。

## 來源與編號

- 來源 B02 是風魔小太郎，與本 kit 無關。本 kit 依名稱對照到本地 `date_masamune`。
- 本地 Rust 模組資料夾叫 `B02_date_masamune`，那只是既有識別字，不代表來源編號。

## 基礎數值

- 生命、法力、攻擊、護甲與近戰射程 250 沿用本地數值。
- 移速 350 取來源。

## 踏火無痕（W→Q）

- 衝刺時帶 300 範圍 aura，這裡等價為「實際路徑兩側 300 內的敵人」。
- 每個觸發的敵人由一道 G-1 追蹤火焰鎖定，命中才造成傷害：
  - 速度 1200、半徑 16、壽命 3 秒，均為 assumed。
- 描述的「隨機」改為決定性的接觸順序，最多 8 個目標。
- Dota 衝刺期間的鎖定狀態不適用，因為本遊戲衝刺是瞬間完成。

## 火焰強襲（E→W）

- 500 半徑魔法傷害加暈眩。
- 不帶本地版的燃燒區。

## 炎之迅捷（R→E 被動）

- 英雄模板雖有力量／敏捷／智力欄位，但 MOBA 戰鬥使用 authored 數值，舊屬性公式（comp/hero.rs）與 StatsAgilityBonus 在 MOBA 路徑沒有消費者，所以每點靈活換算成實際生效的 +1 攻速點與 +1/6 護甲。

## 種子島（T→R）

- 描述寫最終射程 800；本遊戲近戰基礎射程是 250，所以射程加成取 550，不用 KV 的 672（672 是 Dota 128 基礎）。
- 解鎖等級採 6/11/16。
- 「停頓」用既有的攻擊暈眩機率實作。

## 與本地 kit 的差異

- 本地四招（`flame_blade`、`fire_dash`、`flame_assault`、`matchlock_gun`）保留不動。
- H02 以 `b04_*` 新 ID 附加；build 用 `update_existing` 換掉英雄的四個技能欄。
