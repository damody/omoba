## 阻塞

無。kit 需要的新通用能力在本批（errors.md E163）補上，不是英雄專用：

- `bounce_chain`：ability_projectile 的追蹤彈可帶 `bounce`（總命中數、半徑）。每次命中後，在命中目標的半徑內，以決定性亂數挑另一個可見的敵方英雄或一般單位（只排除當下目標），同一顆投射物重新鎖定，直到命中數用完。
- `spell_guard`：host 在敵方指定技能施放成立時，依目標身上的 spell_guard 項目（魔抗、持續、冷卻）套魔抗並開始冷卻。
- ally_area_buff 的半徑上限從 5000 提高到 100000，讓全軍光環涵蓋整張地圖。
