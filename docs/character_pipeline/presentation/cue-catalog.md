# 呈現 cue 目錄

由 `tools\lua\lua.exe docs\character_pipeline\tools\v3_cues.lua` 從 v3 文件與原作 history_nobu（commit f966720）產生，不要手改。機器可讀的資料在 [cue-catalog.lua](cue-catalog.lua)。原作資產只記錄路徑，沒有複製。

## 總計

- v3 文件用到的 cue：1080 個。對到原作資產的有 910 個（high 221、medium 344、low 345），其餘 170 個使用通用佔位特效（`placeholder = "generic"`，音效為 `"generic_sound"`）。
- 條目出處範圍內的原作資產：852 個（粒子 560、音效 292），其中 642 個已對到 cue。
- 信心：
  - **high**：狀態的 cue 對到 notes 寫的原作 modifier 的 EffectName。
  - **medium**：路徑含技能編號前綴，且名稱字詞相同。
  - **low**：只靠同一條目與種類（粒子或音效）判斷，UE 線導入美術時要人工確認。
- 沒對到 cue 的原作資產列在 `unmapped`（依條目），表示 v3 資料還沒有對應的呈現；UE 線可以補 cue，或維持不顯示。

## cue 類型（kind）

依 cue 掛在哪裡推導，給 UE 選通用佔位特效：projectile（投射物）、area（地面區域 zone）、link（tether）、aura（狀態）、summon（召喚與單位模板）、channel（引導事件）、impact（命中回呼 on_hit）、gesture（名稱含 gesture）、其他獨立 cue 依資產分成 effect 或 sound。一個 cue 有多種用途時，`kind` 是最常見的那一種，`kinds` 列出全部。

| kind | cue 數 |
|---|---|
| effect | 377 |
| aura | 284 |
| sound | 271 |
| projectile | 78 |
| impact | 32 |
| gesture | 27 |
| channel | 5 |
| area | 3 |
| summon | 2 |
