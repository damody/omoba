# 宣告式暈眩效果（2026-10-05）

## 計畫與完成內容

1. Lua 技能效果新增 `stun_enemy { duration_key = "stun_duration" }`，由共用內容模型與 Rust registry 生成器驗證；遊戲執行的是編譯 Rust，不是 Lua runtime。
2. 每級時間必須完整、有限且介於 1/1024–60 秒；單位敵方目標、正值有界射程、目標存活與隊伍判定沿通用效果預檢。敵我效果衝突拒絕，不先提交傷害再發現暈眩無效。
3. 使用既有 `BuffId::Stun`／BuffStore，阻止移動、普攻與施法。刷新採既有最大剩餘時間，不讓短控場縮短長控場；不冒充減速，也不另造角色專用狀態。
4. 先鋒破岩擊的 Lua 資料加入 0.75／1／1.25／1.5 秒暈眩。Unreal 仍使用通用生成類別、既有註冊暈眩視覺與權威動畫暫停路徑，沒有新增英雄 C++ 或 Blueprint。
