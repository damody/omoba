# omfx Pregame UI Content and Session Mapping

Pregame menu content is owned by scripts content data. The default catalog lives
at:

```text
scripts/base_content/assets/pregame_ui/catalog.json
```

Content mods should replace that catalog and its referenced assets instead of
editing `omfx` Rust source. `omfx` also accepts `OMFX_PREGAME_CATALOG` for a
direct catalog path and `OMFX_CONTENT_ROOT` / `OMB_CONTENT_ROOT` for a staged
content root that contains `assets/pregame_ui/catalog.json`.

## Map and Difficulty Mapping

When a player selects a map and difficulty, `omfx` creates a per-session config:

- `session_id`: generated by the frontend for this one game session.
- `map_id`: selected catalog map `id`.
- `story`: selected catalog map `runtime` if set, otherwise `story`.
- `difficulty_id`: selected catalog difficulty `id`.
- `difficulty_config`: selected catalog difficulty `config`, defaulting to `id`.
- `kcp_addr`: `OMFX_SERVER_ADDR`, `OMB_SERVER_ADDR`, or `game.toml` server config.

The session launcher passes these values to the backend executable as:

- `OMB_SESSION_ID`
- `OMB_MAP_ID`
- `OMB_STORY`
- `OMB_DIFFICULTY_ID`
- `OMB_DIFFICULTY`
- `OMB_KCP_ADDR`
- `OMB_CONTENT_ROOT` when a content root is configured

The local `sim_runner` uses the same `OMB_STORY` value to resolve the story data
directory, so backend and local render simulation stay on the same map/runtime.

## Backend Executable and External Mode

`omfx` does not depend on the `omobab` crate and does not run `cargo run` or
`cargo build` for the backend. It only starts an already built executable.

Use `OMFX_BACKEND_EXE` to point at a packaged or staged backend binary. If unset,
`omfx` searches near the current executable and common staged `target` output
directories.

Set either of these to connect to an already-running backend without owning its
process:

```text
OMFX_EXTERNAL_BACKEND=1
OMFX_DISABLE_SESSION_LAUNCHER=1
```

In external mode, menu idle still does not connect to backend. The connection is
created only after map and difficulty selection, and teardown does not kill the
external backend process.

## Legacy Autostart

For temporary developer compatibility, `OMFX_LEGACY_AUTOSTART=1` starts the first
enabled catalog map and difficulty during plugin initialization. The default path
is pregame menu first.
