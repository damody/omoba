## 4. 規則與工具（復工必讀）

- **live 輸入的修改：**
  - 一律在影子改好，再用 `land_to_live` 放回。
  - land 前，先在影子跑完 land 的全部檢查：generator `--check`、lua_content_check、cargo check、items 和 hero 的 manifest 測試。
  - land 失敗也會占住 build 鎖。
- **build 鎖：** `target/locks/build_ue_moba`。
  - 不要手動刪鎖。
  - 別人正在跑 UBT 時，不要跑 `check_live_consistent --ubt`；曾經因此卡鎖 51 分鐘。
- **磁碟：**
  - 影子 cargo 一律設 `CARGO_PROFILE_DEV_DEBUG=0`、`CARGO_PROFILE_TEST_DEBUG=0`。
  - 一次只跑一個影子 cargo。
  - 結束後執行 `tools\lua\lua.exe scripts\cargo_target_retention.lua <dir> --drop-pdb`。
  - B 的 `target/m3p/sc3` 還沒清。
- **junction：**
  - `target/` 下的影子含有指向 live 的 junction。
  - 不要遞迴刪除。11-07 曾因此清掉 8 個 submodule。
  - 要先移除 reparse point。
- **content hash：**
  - 任何改到內容的 land，都會讓 C 已 stage 的 UE 影子失效。
  - C 錄影期間，其他線要暫停內容 land。
- **程序：** 只停自己的 task 或 PID，不要按程序名 kill。實機局限 10 分鐘內。
- **CRLF：** gen_item_v3 寫出 LF，但 live 的 item_shop_v3／item_texts_v3 是 CRLF，要手動轉換。
- **數值：** 依 D13 不改數值；依 D21 功能優先於平衡。
