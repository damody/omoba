# 玩家指南（omfue MOBA）

從啟動、選角、對局到再開一局的操作說明。內容依 2026-10-26 的實機版本整理；預設按鍵取自 `OmPlayerControlProfile.cpp`，可在遊戲內「操作設定」改鍵。

## 1. 啟動

前置條件：Windows、Unreal Engine 5.8（找不到時依序試 `UE_5_8_ROOT`、`UE_ROOT`、`D:/UE5.8`）、已完成建置。

| 情境 | 指令 |
|---|---|
| 正式 MOBA demo（1 位玩家＋9 個電腦，真人選角） | `run_ue.bat` |
| 同上，略過重建 | `run_ue.bat --no-build` |
| 本機雙人對戰（1 台 server + 2 個畫面） | `tools\lua\lua.exe scripts\run_moba_split_local.lua --no-build` |
| 打包版（不需要 Editor） | 在上一列加上 `--packaged-game <打包目錄或 OmGame.exe>` |

本機雙人對戰會依序開兩個視窗，玩家 1 在隊伍 1，玩家 6 在隊伍 2，其餘 8 個位置由 bot 遊玩。

## 2. 選角

開局前會出現選角畫面：選擇英雄後送出，雙方都鎖定後才會進入對局。目前可選的英雄包括晨光導師系列訓練英雄、雜賀孫市、伊達政宗、阿松、阿市、稻姬、淺井長政、玉子、村上義清。

## 3. 對局操作（預設按鍵）

### 移動與攻擊

| 操作 | 按鍵 |
|---|---|
| 移動／攻擊目標 | 滑鼠右鍵 |
| 攻擊移動 | `A` 後點左鍵；`Shift+A` 直接在游標位置攻擊移動 |
| 停止 | `S` |
| 原地堅守 | `H` |
| 只攻擊英雄 | 按住 `~` |
| 指令排入佇列 | 按住左 `Shift` 再下指令 |
| 取消瞄準 | `C`，或 `Esc` |

### 技能與道具

| 操作 | 按鍵 |
|---|---|
| 施放技能 | `Q` `W` `E` `R`（指定型技能按下後點左鍵確認）；有第 5 技能的英雄另有 `X` |
| 升級技能 | `Ctrl+Q`／`W`／`E`／`R`／`X`，或點技能格上的升級按鈕 |
| 對自己施放 | `Alt+Q`／`W`／`E`／`R`／`X` |
| 切換施放模式（快速施放／指示器） | `Shift+Q`／`W`／`E`／`R`／`X` |
| 召喚師技能 | `D`、`F` |
| 道具欄 | `1`～`3`、`5`～`7` |
| 插眼 | `4` |
| 回城 | `B`（移動、攻擊或施法會中斷回城） |
| 商店 | `P`，或點畫面上的「商店」 |

技能格會顯示冷卻秒數與等級；施法被拒絕時，畫面左上會顯示原因，例如「冷卻中」「法力不足」「需要指定目標」。引導技能（例如晨光引導者的 R）施放期間，英雄被暈眩、移動或死亡都會立刻中斷。

### 召喚物

| 操作 | 按鍵 |
|---|---|
| 指揮召喚物移動 | `Alt+右鍵` |
| 解除召喚物 | `Alt+S` |

### 鏡頭

| 操作 | 按鍵 |
|---|---|
| 鏡頭跟隨英雄（按住） | 空白鍵 |
| 鏡頭回到英雄 | `F1` |
| 切換鎖定鏡頭 | `Y` |
| 切換邊緣捲動 | `F9` |
| 平移 | 方向鍵，或滑鼠移到畫面邊緣 |
| 拖曳鏡頭 | 按住滑鼠中鍵 |
| 縮放 | 滑鼠滾輪 |
| 看隊友 | `F2`～`F5`（點左上角的隊友卡也可以） |

### 介面與溝通

| 操作 | 按鍵 |
|---|---|
| 計分板 | `Tab` |
| 角色數值 | `C` |
| 隊伍聊天／全體聊天 | `Enter`／`Shift+Enter` |
| 聊天紀錄 | `Z` |
| 信號輪盤／撤退信號 | `G`／`V` |
| 在地圖上發信號 | `Alt+左鍵` |
| 表情 | `T` |
| 隱藏 HUD／血條／名稱 | `O`／`N`／`U` |
| 診斷資訊（FPS、RTT） | `Ctrl+F` |
| 截圖 | `F12` |
| 滑鼠鎖定在視窗內／解鎖 | 單按一下 `Ctrl`（左右皆可；按住期間有按其他鍵或滑鼠就不算，所以 `Ctrl+Q`、`Ctrl+右鍵`、`Ctrl+F` 不會切換） |

滑鼠預設鎖定在遊戲視窗內（視窗模式也是）。切換時畫面上會短暫顯示「滑鼠已鎖定／已解鎖（Ctrl 切換）」，操作設定的「單按切換滑鼠鎖定在視窗內」一列也會顯示目前狀態，並可改成其他按鍵。視窗失焦（例如 `Alt+Tab`）、開啟操作設定、聊天或聊天紀錄，以及出現結算或對戰終止面板時，游標會暫時放開；回到遊戲後恢復你選擇的狀態。

## 4. 對局目標

地圖有三條路。推進的順序是：

1. 推倒一路上的外圈塔；
2. 打倒該路的兵營；
3. 兵營倒下後，主堡塔變成可以攻擊；
4. 主堡塔全倒後，主堡變成可以攻擊；
5. 推倒對方主堡即獲勝。

兵營與主堡塔會在一段時間後重生。打塔時要有己方小兵在塔的攻擊範圍內承受仇恨，英雄單獨進塔會被塔集中攻擊。

## 5. 結算與再開一局

主堡被推倒後，雙方都會看到結算面板，例如「勝利」或「敗北 · 對戰結束 · 勝方：隊伍 N」，以及 K/D/A。點「離開對局」結束。正式 MOBA 入口在所有玩家都是本機真人時，可以在結算後準備下一局。

如果伺服器偵測到狀態不同步或中止比賽，畫面中央會顯示「比賽已終止」與原因，頂部列也會顯示「比賽已終止」；此時遊戲輸入會停用，請點「離開對局」。

網路短暫中斷（約 2 秒沒有收到伺服器進度）時，頂部列會顯示「連線中斷，等待恢復」並暫停操作，連線恢復後自動回到正常；中斷超過 30 秒會判定為「與伺服器的連線中斷」，client runtime 會自動嘗試重新加入同一場（英雄在斷線期間留在場上），重新加入後即可繼續操作。

## 6. 已知限制

- OS 150% DPI 縮放尚未驗收；1280×720 與 1920×1080 視窗都已驗過 HUD 排版。
- 真雙機 LAN 尚未驗收（目前是同一台機器上的 1 台 server + 2 個畫面）。
