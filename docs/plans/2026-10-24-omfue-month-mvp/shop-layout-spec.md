# 商店版面規格（依參考圖量測）

參考圖：`target/mvp-a3/lol-shop-reference-2.webp`，2000×1013。所有尺寸在程式中定義於 `FOmShopSpec`（`omfue/Plugins/OmRuntime/Source/OmRuntime/Public/OmHudViewportSpace.h`），本文件是它的來源與量測方法。

## 量測方法

- 先把 webp 原樣轉成 24-bit BMP 和 PNG（Grok CLI 轉檔，不縮放、不改像素），放在 `target/session-shop/ref/`。
- 用 Lua 讀 BMP（`target/session-shop/img.lua`、`probe.lua`）。沿水平或垂直線列出像素值，找金色外框（約 sRGB 101,93,71 到 127,120,91）、分隔線（約 42,54,50）和圖示邊框（約 36,42,47）的位置。另外輸出放大三倍、每 10px 畫一條格線的局部圖，人工核對。
- 下表座標都是參考圖的像素；「佔比」是除以畫面高 1013（尺寸）或寬 2000（水平位置）。

## 縮放規則

- 縮放比例 S 等於 HUD 高度除以 1013，所有長度都乘以 S。720p、1080p、1440p 維持相同比例。
- 主框必須放得進 HUD 標頭（隊友卡）和指令列之間的帶狀區；寬度也要容得下快速購買欄。放不下時 S 等比縮小，排版不變。
- S < 0.59 時，這個排版放不下可讀的文字，改用原本的直式堆疊商店（compact），可以捲動。
- 文字不隨 S 縮放，維持 HUD 的可讀內文大小（`FOmHudReadableText`）。S 較小時，搜尋列高度和道具格寬度以內文能放下為下限。

## 自動檢查

`Om.Runtime.ShopLayout` 會把視窗開成 2000×1013（和參考圖同比例），量測下列區塊：主框、左區、右區、快速購買欄、分頁列、底部列、進階道具列、佇列按鈕、格子圖示、格距。尺寸誤差（相對於區塊本身）和位置誤差（相對於畫面）都必須 ≤ 3%。參考數字直接寫在測試裡，不讀 `FOmShopSpec`，所以改動版面常數時，不能連目標一起改掉。帶 `-om-shop-layout-capture=<dir> -om-shop-reference=<參考 png>` 執行時，會輸出誤差表（`shop-spec-errors.md`）、疊圖（`shop-overlay-*.png`）和並排圖（`shop-side-by-side-*.png`）。

## 與參考圖仍不同之處

- 文字大小：HUD 的可讀內文大小隨畫面高度變化（E152）：720p 為 11px，1080p 為 14px（參考圖約 15px）。
- 底部列多了出售用的背包六格。我們的出售流程是先選背包格、再按出售；參考圖的背包在下方 HUD。S ≥ 0.9 時，交易與復原的狀態文字也放在底部列。
- 快速購買欄的三組是常用（初始級）、建議（成品）、佇列。目錄沒有藥水、眼這類消耗品。
- 分類列是 10 個數值分類，不是參考圖的職業分類；目錄沒有職業標籤，也沒有攻速、法強、魔抗。
- 道具格右上角保留小的「合」查看配方按鈕。
- 實機 720p：開商店時隊友卡暫時收起，帶狀區從標頭頂端的固定列開始（E151），S 約 0.68，使用參考排版。
