# Upgrade preview

## Requirements

- An owned known rank below its authored maximum exposes the next rank, required hero level and base numeric summary, even when the gate is not met or no points remain.
- Rank zero shows first learning with no invented current rank. Maximum rank shows no next rank.
- The normal ability tooltip and the upgrade button use the same comparison and typed reason. Rebound upgrade shortcuts appear correctly.
- Unknown identity, invalid rank, replacement, unavailable owner and retired HUD cannot retain an old skill comparison.
- Base catalog numbers are labeled as base data; the existing authority remains responsible for upgrade admission and final outcome.
