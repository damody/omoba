# Recall progress requirements

- Total duration comes from the same authored/default contract as authority; missing or invalid total never creates an inferred bar.
- Only a disclosed living owned hero in active MOBA play with enabled recall and positive bounded remaining time shows progress.
- Progress is1 - remaining/total and changes only on published state; repeated paused state does not advance locally.
- Zero remaining hides without asserting completion. Stale packets, unknown identity, invalid numbers, replacement, reset and retired HUD cannot retain a prior channel.
- Actual HUD and native capture use the same shared Slate strip; it is read-only and cannot consume gameplay input.
