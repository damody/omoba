# Design

Move the existing default8/range1..60 recall duration rule to the content model. Both template validation and codegen use that policy. Include the parsed duration in the freshness manifest and expose a generated registry getter; bridge copies it into a new typed UI-only total field. No transport/C ABI expansion. Existing compiled/runtime recall rebuild guards protect the duration contract. A shared actual Slate strip uses the owned published remaining/total, never a local timer or inferred first sample. Invalid/unknown owner, missing protocol, non-playing/dead, bad numbers, cancellation, reset and retirement hide the strip. Same-life older tick/sequence cannot rewind a displayed snapshot; newer channel restarts remain valid. Keep the legacy recall text/shortcuts and all authority rules.
