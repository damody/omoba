# Ordinary attack lifesteal

Connect the existing shared Lifesteal stat to explicitly classified ordinary attacks. Native Attack packets use the stronger of the explicit physical-leech flag and shared stat, avoiding duplicate application of a stat already authored into a flag. Ability/item/environment/reflect damage retain explicit flags only. Primary native and typed script ordinary projectiles capture the shared rate at launch; late buffs do not change an in-flight result. Serial actual HP loss, source life, healing reduction and committed vitals reuse the accepted native leech mechanism.
