# Design

UnitStats sums Lifesteal and clamps the normalized shared rate to 0..1. ProjectileOrigin adds a serde-default authority-only attack_lifesteal field. Only explicit primary native/script ordinary launches set it. Inherited script children clear it, visual shots retain zero, and NORMAL damage profiles never imply eligibility. Exact origin source, ordinary classification and non-missed launch are checked again at impact. Source death permits existing projectile damage but cannot heal or credit a replacement generation. Post-defense physical damage earns proportional actual HP loss; magical/pure components earn none. Existing received-healing and public source vitals apply once.

No new ABI slot, public schema, UI path, item, network match or historical frontend change. Preserve original bytes, freeze inputs, run fresh formal suites, retain failures and validate owned process retirement before releasing source freeze.
