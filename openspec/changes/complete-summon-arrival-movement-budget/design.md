# Design
Maintain a private per-world HostMovement record containing the exact Tick and canonical Entity generations moved by summon_tick. Reset it at each system invocation before pause/delta guards; record only actual nonzero coordinate changes, including sub-quantum-squared steps. The script adapter rejects summon autonomous steps if either a host target remains or this exact entity already moved in the current tick. Stale ticks cannot block later movement. No serialized navigation field, wire/ABI extension, name rule or local timer. Direct forced set_pos remains available. The record is phase-local, reset before every future summon phase, and is not replicated or future gameplay state.
