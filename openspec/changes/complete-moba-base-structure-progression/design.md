# 設計

地圖可選 base_structures，定義水晶位置／HP／重生時間、基地雙塔位置／HP／重生時間與百分比、超級兵及其替換砲車身份。省略則保留既有解鎖策略。

每路水晶須該路全部塔權威退休才能攻擊；任一水晶處於重生等待時開放兩座基地塔；主堡另須雙塔均退休。水晶恢復立即關閉相關攻擊入口。已出生超級兵保留；後續該路波次停止強化。三路水晶全滅每路兩超級兵。基地塔重生40% HP，均依暫停的遊戲時鐘，不在結束後重生。重生使用新 entity 世代，全部私有 deadline/state 納入 replay digest。

視覺接受發現模型重疊後，採共享幾何尺度2（4800邊長），包括所有路線／牆／地表與營地中心；戰鬥射程、速度及模型保持原單位。正式線塔偏移2200/1600/1000，水晶650，雙塔400，minimum_spacing250。驗證同時檢查間距與最短路線真實弧長（整數平方根保守取整），避免依水平座標推算塔位。技能隔離fixture位置依全部公開幾何上界加安全距離，不再硬編y2500。

原生類型加入水晶／基地塔，但公開相容建築 admission 類別不變；靜態呈現 ID 明確保留，超級兵使用獨立保留範圍避免改動原 catalog ID。沿用現有模型，不宣稱原創水晶美術或完整 LOL 數值。
