# Design

RestoreManaSelf does not consume a cast target. Standalone self restoration remains no-target; a targeted combination must contain a separate effect that consumes that same unit/point target. The target-consuming effect supplies shape/range/allegiance admission. Resolve and admit the entire effect plan before staging any caster mana, regardless of declaration order. Keep other existing exclusive movement/channel/geometry policies; do not broaden SpendManaSelf or other self effects in this batch.

The current host already stages ManaPool changes in a serial managed transaction and discards them on RErr/panic; use it unchanged. Mana restoration remains caster-local, capacity-limited and separate from target healing/healing reduction. Metadata mana cost is still reserved once before script effects, so restoration cannot finance an otherwise unaffordable cast.

Existing lumen_aid gains authored caster mana restoration10/15/20/25, alongside the unchanged ally/self heal140/220/300/380. Names/values are content, never runtime dispatch. No new hero, ability identity, wire shape or ABI.
