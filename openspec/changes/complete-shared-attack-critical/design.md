# Design

UnitStats resolves a caller-supplied base chance and default multiplier plus shared chance modifiers and positive absolute multiplier. Existing script getter defaults remain 0 chance/1x. Native DamageInstance keeps its legacy hero base chance and 2x default; property/unit bodies have zero base. Projectile attack paths retain their previous zero implicit base and use 2x only when the shared chance opts in. All share deterministic operation1. Native damage respects can_crit, applies multiplier only to physical damage before defenses and lifesteal, and avoids before critical evaluation. Native hero and explicit AttackHoming ordinary shots commit the amount once at launch; visual pellets, generic skill shots and source misses do not acquire critical damage. This batch does not add a new critical presentation cue.
