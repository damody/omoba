# Design

Codegen derives bRequiresManaPool from the closed SelfRestoreMana operation. The existing OmGenerated world bridge copies it alongside validated identity/name/description into the typed OmRuntime summoner row. A shared native policy reads that flag and the current owned hero's existing mana support/current/max fields; OmRuntime never includes OmGenerated or creates a reverse dependency. Positive finite capacity and finite current within [0,max] are required; zero current and full current are both usable. Existing non-resource summoners and synthetic unknown catalog rows retain their existing policy; unknown identity admission remains the separate Rust/bridge catalog contract. Resource metadata never authorizes an unknown input. No spell/hero name branch, new balance, FFI ABI field or authority mutation.

Card disable/reason, direct/queued input guard and self preview share the same predicate. Current cooldown keeps priority. Self previews never inherit blink movement or stun/silence restrictions. Missing/invalid mana gives an explicit unavailable-resource reason rather than insufficient mana. Existing scope clearing/retirement and owner row validation remain required. Add generated arbitrary-id coverage and native actual action-owner/card/tooltip/resource-transition cases. Concentrated acceptance is full codegen tests, UE5.8/staging, focused native regressions and source consistency; unchanged backend/core suites retain the previous sealed2100-test acceptance, not a new rerun claim.
