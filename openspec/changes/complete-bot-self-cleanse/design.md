# Design

Expose a read-only canonical has_cleanseable_controls predicate beside cleanse_controls, sharing exact supported slow recognition. Add a typed, bounded active-item selector for self cleanse using existing role active-use policy and ready inventory slots. Run it before the general stunned-owner wait and shopping/normal item decisions, but after current phase/pause/life/disclosed owner and recall/channel gates. No threat or missing-HP requirement: control presence is the owner-visible trigger. Never bypass the stun gate for other actions. Preserve orders through the authority's existing self-cleanse item path. Cover canonical controls/slows vs voluntary/malformed effects, policy/cooldown/slot selection and actual formal60Hz bot input, cooldown, retained command/buffs, pause/death and replay. No new items/IDs/default loadout/wire/ABI/network match.
