# Requirements

- Existing scout identity/values remain stable; detection trinket is independently configurable.
- Placement spends one charge into one source; recharge/lifetime use game time and freeze during pause.
- Detection reveals in-range stealth up to authored level with LOS, never grants opposing-team vision, and disappears on expiry/death.
- Generated Unreal details show authored identity, explanation, placement range, sight radius and lifetime; unknown catalog IDs show none.
- No new protocol/wire layout or automatic in-match loadout switch.
