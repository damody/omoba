## ADDED Requirements

### Requirement: Connected concealment regions
Distinct capsule pieces connected directly or transitively SHALL share concealment regardless of authoring order. Capsule exterior corners SHALL NOT create false connections. Runtime targeting, replication and fog SHALL use the same compiled topology.

#### Scenario: Bent continuous brush
Given a source and target in different connected branches, visibility passes the brush predicate while retaining range, wall and detection requirements.

### Requirement: Current cast interaction guidance
Ability tooltips SHALL describe Normal, Quick and QuickWithIndicator activation using the current control profile and retain published target/range guidance.
