# Design

Add typed AttackHoming to the existing stable projectile trajectory ABI; rebuild host and DLL together with Rust1.95.0. The host rejects attack classification for child callbacks, managed casts and non-single-target specifications. Source misses clear damage and attached control at launch. A separate authority script_attack flag participates in the existing impact evasion gate, never the native hero normal_attack flag. Ordinary script Homing/Straight retain their current semantics. Dead-source flight attribution and ordinary retirement remain.
