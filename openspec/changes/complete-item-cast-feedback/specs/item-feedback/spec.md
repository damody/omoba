# Item feedback requirements

- Targeted item preview uses the current selected slot/catalog identity and its finite disclosed cooldown.
- A unit-target item only evaluates range from a currently disclosed source/target pair; an allied, unavailable or unknown target cannot produce a ready hint.
- A point item displays its generated executable area and reject-on-out-of-range guidance.
- Item-specific state unknown is distinct from a valid free/ready item. Replacement, invalid metadata, hidden/stale entities, source clearing and retirement fail closed.
- No ability mana, silence or movement restrictions are inferred for items. Existing authority checks and input paths remain unchanged.
