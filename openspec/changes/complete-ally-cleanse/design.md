# Design

Unit-friendly authoring without extra scalar keys composes with existing friendly and caster-local resource effects. Generic preflight validates the complete plan; a strict instant source/generation/range packet uses existing AddBuff outcomes, binds to the serial caster and revalidates the living target/team/range before canonical cleansing. Never store the transport marker. Generate truthful per-rank cleanse text, omit unsupported legacy numeric previews, preserve stable IDs and ABI. Cover schema, Lua, source/target/sibling atomicity, actual friendly formal60Hz cast, retained statuses, resources/cooldown/pause/reapplication/replay and native tooltip. Freeze provenance before edits, retain failed cohorts, full Rust/backend/UE/catalog and independent evidence closure.
