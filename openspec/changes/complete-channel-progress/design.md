# Design

Decode recovery_channel.total_raw from the existing bounded public buff JSON into an optional typed UI ChannelTotalSeconds. Validate identity, exact schema, finite fixed-point total and remaining range. Never infer total from the first remaining snapshot or a shop item name.

A common native model binds living playing owner/hero generation and ordered hero/buff snapshots. Exactly one valid disclosed channel is rendered. Repeated/paused snapshots do not move progress, older snapshots cannot rewind, completion/cancellation/life/scope/retirement removes it. Widget reads current model only, without local timer. Attach the read-only strip alongside recall feedback in the real HUD. Preserve historical acceptance and prove all Rust inputs unchanged to inherit the previous1839+9 result honestly.

Disclosure boundary: direct full native snapshots carry the validated total. Existing public-score BVS1 intentionally strips payload and cannot show this optional progress strip; details still disclose remaining. A future bounded versioned public total extension is tracked separately. Nonzero opaque visual keys retain all64 bits, including negative int64 representations.
