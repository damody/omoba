# Self transformation contract

- All authored ranks of both shipped transformations retain their modifier values and duration.
- Malformed JSON, invalid rank, explicit wrong type, null, negative, subquantum, excessive or fractional-count values fail without outcomes.
- Omitted extras use checked authored data; explicit zero is retained where allowed.
- Only living self casts commit one buff. Recasts refresh one entry without stacking and expiry removes the modifiers.
- Formal 60Hz casts charge mana/cooldown once, pause freezes duration, and visual multishot remains one damaging normal projectile.
