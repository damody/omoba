# Design

Seed combat lookup for every living-generation CProperty body, then preserve Unit overrides and Hero precedence. Read shared bounded evasion/negative-evasion and miss modifiers. Add stable deterministic miss RNG operation2 without changing existing dodge0/crit1 streams. Apply miss/evasion only to can_dodge hits; ordinary ability/true flags remain unavoidable. An avoided hit has zero actual damage, total and healing. No global RNG, duplicate defense, new ABI, item, ability or UI contract.

Concentrated eight-workspace Rust, formal60Hz lane AI, backend/UE5.8/native regression and whole-source frozen-byte proof. Preserve immutable helper versions and exact failed evidence. Retry closure only with byte-identical archive checks.
