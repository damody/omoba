# 設計

Lua basis-point曲線索引為被敵方有效擊殺、且尚未以有效擊殺中斷的死亡次數；缺欄空曲線停用。最多101項、首項10000、單調不增且每項0..10000；超出索引維持末項。整數u64乘法除10000向下取整，不使用浮點或renderer clock。

只折價普通英雄擊殺金，不折價首殺、終結賞金、助攻金或XP。成功權威獎勵結算後，受害者連敗加一、擊殺者清零。匿名、同隊、強制死亡、不合法來源、未成功支付、暫停與非Playing不得改變；既有lethal_pending確保同一生命只結算一次。玩家roster跨死亡重生保存，digest包含政策與狀態。

正式server使用generated政策；局部fixture預設停用保留兼容。內容hash及runtime hot-reload相容性檢查涵蓋曲線，修改必須重建所有正式消費端。ABI維持33，既有owner Gold通道直接傳遞實得金額。
