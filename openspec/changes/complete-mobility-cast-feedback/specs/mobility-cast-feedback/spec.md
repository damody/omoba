## ADDED Requirements
### Requirement: Content-derived mobility
Both executable dash contracts MUST publish a movement requirement without identity or cosmetic inference. Ordinary point/area skills MUST remain independent of root.
### Requirement: Public source root feedback
Root guidance MUST use only current disclosed owner source snapshots and exact generation. Invalid, retired, revoked, unknown, duplicate or malformed relevant data MUST not claim clear movement. Permanent effects MUST have no invented countdown. Root removal MUST refresh without pointer motion.
### Requirement: Actionable read-only aiming
Learned mobility skills MUST explain root and zero ground displacement while preserving existing higher-priority cast blockers. Ordinary point self-casts MUST remain eligible. Hints MUST NOT submit, cancel or gate commands, or imply an authority ACK.
### Requirement: Retirement
Owner policy and bridge root facts MUST clear on owner/source retirement and target-shape replacement.
