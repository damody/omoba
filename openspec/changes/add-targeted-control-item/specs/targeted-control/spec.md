## ADDED Requirements

### Requirement: Generic targeted control
The authority SHALL support optional stun, root or silence on validated enemy unit items, require a bounded positive duration and reject building targets before mutation. Surviving targets SHALL receive canonical status with existing refresh, pause and expiry semantics. Missing optional control SHALL preserve existing item behavior.

### Requirement: Accurate generated guidance
Generated native metadata SHALL preserve kind and fixed-point duration from the authored catalog. Shop/hotbar guidance SHALL describe control and building exclusion, and malformed control metadata SHALL disable use. Single-PC tests SHALL exercise the actual catalog and public status path.
