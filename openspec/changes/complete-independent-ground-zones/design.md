# Design

Author optional typed zone_lifetime enum caster_bound/independent in shared ability model. Validate only point-circle zones with complete bounded rank extras. Compile a zone_independent bool to AbilityConst; script handler reads the same compiled value. Legacy omitted lifetime and seven-field zone payload remain caster-bound and stable. Independent payload adds only lifetime="independent". FlameAssault stays caster-bound. FlameBlade gains2second independent burn at0.5second intervals,10/15/20/25 damage, using the existing generic point blast/zone helper; no hero identity branches in host runtime. Lua builds tooltip from the same field.

BuffStore owns a separate bounded independent-zone book keyed by exact source Entity generation plus buff key. Cap128 global/8 per exact source; checked monotone u64 leases, key bound128. Capture source faction and existing ProjectileOrigin credit at ingress, strip script snapshot and every attack/crit/leech role. Source-owned mirror buff serves the existing public status while source is alive; death clears that mirror but never the independent book. Explicit remove cancels book and mirror; refresh replaces the lease and resets phase/lifetime. Generic add refuses independent payload without checked scheduling.

Drain attached and independent clocks into one canonical due-time/source-generation/key stream. Independent host-only pulse carries source/key/lease, not supplied damage or credit. Serial expansion looks up the exact current lease and samples live hostile non-building targets; no live source requirement. It emits shared RawDamage with captured origin, using normal defenses/shields/credit without attack effects. Retain expired book entries until next drain so an exact final pulse can settle; explicit cancel/refresh invalidates already-queued old pulses immediately. Death must not invalidate independent pulses. Tick clocks use scaled production dt; zero/negative/pause/terminal do not advance gameplay. Preserve bound-source earlier-lethal cancellation behavior.

Managed cast admission validates all zone data and reserves projected independent keys/capacity/lease budget before resources, cues or blast escape. Independent AddBuff is emitted before the initial blast, capturing source provenance before reflected/earlier side effects. Failed admission must leave mana/cooldown/HP/visuals/book unchanged. Add host-only pulse variant at enum end and reject it from managed scripts.

Canonical replay diagnostic includes zone phase, remaining life, exact key/source generation, immutable faction/credit and lease counter, including retired sources. Do not leak this private book into public unit/projection data. Existing public damage/explosion pipeline remains the disclosure boundary. Extend meaningful kernel, lease/capacity/expiry/order/serialization, formal production60Hz death/new-life/source reuse/credit/pause/replay and real native authored tooltip acceptance. Freeze after owned codegen, fresh Rust/backend/UE/native92, source proof, raw failure preservation and actual image review. No new real network match, quota reset, commit/push or omfx work.
