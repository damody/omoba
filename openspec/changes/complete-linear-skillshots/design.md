# Design
One exclusive instant point LineDamage effect derives preview width directly from its rank key. Width1/1024..5000; range1/1024..10000; damage0..1000000; complete ranks and existing scalar rules. No simultaneous special aim_geometry or effects. Line is a capsule from source to requested endpoint, range-clamped in deterministic fixed point; zero axis/unsupported coordinate rejects atomically. It pierces terrain without moving its caster, targets live hostile nonbuildings by center, exact boundaries inclusive, canonical entity generations and max128 resolved hits before any output. No attack/critical/leech roles. Shared RawDamage retains live defense/shield semantics.
Compiled line widths derive from actual executable effect, never names/cosmetics; runtime loader and build generator must agree and semantic aim signature includes width. Bot EnemyLine counts unique disclosed live enemies with bounded512 observations/32 candidate endpoints, same shared endpoint and capsule, max128 hits, deterministic focus/coverage/distance/id ordering and normal mana/control admission. Existing cone/path/point behaviors remain.
Append-only lumen_ray skill and training_line_mage loadout use shared visual profile. Native path outline reuses existing bounded capsule renderer; nonmovement paths have separate straight-line/terrain-piercing guidance and missing-direction state, without root gating. Existing displacement guidance remains. Actual Q hover plus native preview tests prove generated data projection. No true network matches.
