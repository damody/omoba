# Design

Append an internal DamageWithLeech envelope accepting only one immediate settled Damage. Ordinary native packets with zero leech remain unchanged and allocate no envelope. Existing native flags travel with the packet; serial admission, packet modifier, shield and HP loss precede healing. Component proportions after base defenses allocate actual HP loss; pure damage earns none, physical and magical rates combine in one checked rational rounding. Overflow fails closed for healing. Source/target exact lives, dead/retired sources, pending removal, self hits and TD layered targets cannot earn leech. Reuse the existing received-healing/cap/no-revival and committed-vitals publication in the same serial outcome, before later independent hits. Nested envelopes/effects are rejected, and managed script casts cannot author this host-only envelope. Diagnostic DamageResult.healing remains an estimate, never an independently applied Heal. Shared Lifesteal stat and projectile leech policy remain future work.
