# Design
Author a closed nearest/owner_focus policy in summon metadata, default nearest. Emit the same typed runtime policy in compiled constants and runtime Lua content. Owner focus requires an exact live summoner hero, matching positive player ownership and faction, and its active AttackTarget command. It supplies only a preferred Entity; the existing summon target admission still decides visibility, life, hostility, range, terrain/LOS and protected targets. Invalid/absent focus falls back to the existing canonical nearest ordering. No new wire command, input scope, ABI method or name-based runtime condition. Opt the authored gunner into owner_focus; existing right-click attack commands therefore provide useful summon coordination.
