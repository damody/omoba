# 契約

- 合法PlayerOwner須在正式roster且與來源Faction同側，死亡主人可收Gold／XP與persistent隊伍效果。
- 8-link召喚鏈有限、generation-aware、同隊；cycle／超限／stale／未知或跨隊owner拒絕。
- 無主隊伍單位只有team objective，不猜個人Gold／XP。
- 正傷害第一次致死固定credit，Death一次消費；來源之後退休／重複Death不更改。
- 非英雄可吸引仇恨與被camp實際攻擊，退休後回頭；LOS／patience規則沿用。
- 仍受Playing／pause／免疫回頭及匿名退休規則約束，沿正式Buff／owner economy。
