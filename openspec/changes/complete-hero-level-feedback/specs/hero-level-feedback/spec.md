# Requirements

- Only a higher level from an already observed valid local hero playing scope creates a notice.
- Initial/scope replacement, duplicate, backward time/level and absent state do not fabricate increases.
- Notice coalesces multiple observed increases and expires after four seconds of presentation time.
- End/reset/retirement clears baseline and notice; retired HUD cannot revive it.
- Real header text uses localized content, readable typography and current HUD visibility/layout behavior.
- No gameplay resources, authority progression, ABI, wire or simulation time are changed.
