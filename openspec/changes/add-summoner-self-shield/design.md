# Design

Extend the shared authoring enum and generated fixed-point operation with amount/duration. Validate positive finite quantized amount and duration<=60seconds, target none only. The immutable summoner plan resolves SelfShield; the exclusive ECS sink grants the existing canonical damage_shield before cooldown commit. Missing BuffStore rejects without partial effect/cooldown. Existing maximum-shield and longer-remaining-lifetime policy stays shared. Healing reduction does not scale shield. No command cancellation or displacement. Lua owns new catalog_id3, amount160, duration2, cooldown180 and descriptive text; existing IDs/default D/F remain unchanged. Generated native catalog and actual tooltip must expose the third choice through the maintained Unreal path. Test parsing, generation parity, plan commit/failure/replay and real ECS shield absorption/expiry/rejection/disclosure.
