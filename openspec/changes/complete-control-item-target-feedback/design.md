# Design

The typed hotbar projection carries the validated control item's non-building requirement. Owner state replaces/clears it with the existing slot lifecycle. A source-relative bridge query first performs existing visibility/life/generation/allegiance/attackability admission, then reports a distinct building refusal from the current published row kind. No actor class/name inference or hidden-state lookup. Ability and non-control item behavior remain unchanged. Feedback is read-only; backend remains authoritative.

Cover actual catalog13 versus11, current building/hero rows, stale generations, unavailable/hidden/allied targets, replacement and retirement; capture shared localized feedback. Build UE5.8, run consolidated native suite and bind exact native-only deltas to prior accepted Rust/backend evidence.
