# Design

Add serde-default launch-miss provenance to ProjectileOrigin and the internal ScriptProjectile outcome. Native and typed script attack admission capture the already computed result once; visual pellets and hit-context children cannot inherit it. Exact source generation must match the projectile owner. At homing arrival, a committed miss bypasses all hit/damage/control envelopes and emits the existing target-only avoidance fact, followed by ordinary retirement. Legitimate zero-damage abilities retain existing semantics. No ABI or public reason/source disclosure is introduced.
