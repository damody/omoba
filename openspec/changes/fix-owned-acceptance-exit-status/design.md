# Design

Reuse moba_session_process and tools/lua/lib/process.lua run_owned_to_files/validate_owned_exit. One exclusive output directory retains spawn/ready/actual Windows exit/identities/stdout/stderr/receipt/health/error records. No shell or alternative runtime. The child script hash is bound before/after running. An actual nonzero exit always fails, even with a success summary or misleading log. Optional summary must be absent before spawn and end as bounded JSON success=true; no-summary tasks use actual exit only. Current logs plus bounded explicit watch paths sampled at <=170second intervals while waiting. Only journalled original lifetimes may be stopped on errors.

Regression uses actual fixed-Lua children: misleading early success plus summary followed by error, zero exit without required summary, full success, exit-only success, stale evidence refusal and tampered lifetime/executable/retirement receipts. Existing owned-run platform suite remains the low-level actual Windows exit regression. This batch changes shared workflow inputs only; no engine/authority game needed. Prior UE/native/Rust proofs may only be inherited after complete source delta verification of exact added workflow files.
