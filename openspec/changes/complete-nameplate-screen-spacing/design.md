# Design

Keep the O(N log 64) shortlist and measure at most 64 current candidates. Project the same mesh-top anchor that TickNameplate uses; never read last-frame desktop bounds. Sort retained rows with the existing total priority order. Measure the inner Slate root independently of the collapsed UUserWidget wrapper, multiply logical size and three-unit padding by the current viewport UI scale, round projected anchors like Unreal's screen widget layer, and reject overlapping clipped rectangles.

Suppression does not move a plate away from its entity and does not change public selection, authority, team markers or hero visibility. A suppressed row is measured afresh next view and can return when anchors separate. This is bounded greedy admission of the existing shortlist, not optimal packing of every entity. Widget resource release clears the extra layout root. Pending statuses and UI text size naturally change the measured footprint.
